## What's in this repo

This is the source code for the **NeolithAI Agency website** — a fully static, multi-page, English-only site with no frameworks or build tools required.

### Tech stack
- Pure HTML5 + CSS3 + Vanilla JS
- Shared CSS/JS across all pages (`neolithai-shared.css`, `neolithai-shared.js`)
- Netlify Forms for contact & newsletter
- Canvas API for the animated hero visualization
- Neo — AI chat assistant (Netlify Function calling the OpenAI API, GPT-4o)
- SEO: `robots.txt`, `sitemap.xml`, canonical + Open Graph tags, JSON-LD structured data
- Deployed on Netlify with auto-deploy from this repo
